Prohibited Purchase Dashboard

Identify transactions that may require further investigation under OSU P-card purchasing policies.

How to use this dashboard
  1. Select a transaction year.
  2. Choose Description Search or Vendor Search.
  3. Enter a keyword and run the search.
  4. Review matching transactions.
  5. Export results to CSV for follow-up.
Keyword matches indicate transactions for review, not confirmed policy violations.

Description Search

Search transaction descriptions for possible prohibited purchases.

Vendor Search

Search vendor names for merchants requiring review.

Prohibited Purchase Categories

  • Alcohol
  • Cash and ATM transactions
  • Decorations
  • Donations and sponsorships
  • Gasoline
  • Gifts and gift cards
  • Insurance
  • Late fees
  • Mail and postage
  • Moving expenses
  • Personal purchases
  • Individual memberships and dues
  • Salaries, wages and benefits
  • Service and incentive awards

Ask the Database

Ask a question in plain English and receive an answer based on the P-card transaction database.

How to use

Type your question and click Analyze. The system uses Gemini AI to interpret the question and retrieves results from the database.

Example questions
  • How many transactions occurred in 2014?
  • What was the total spending in 2013?
  • Which 10 vendors received the most money in 2014?
  • Which employees had the highest spending in 2014?
